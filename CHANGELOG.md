# Changelog

## 0.1.0 - 2026-11-05

Initial release of the always-on Delta Chat identity, browser setup and
messaging, authenticated MCP tools and room subscriptions. Includes the OpenCode
v1 plugin and explicit-reply OpenCode v2 and Claude Code integrations.

Linux x86_64 service downloads include a self-extracting executable, built web
assets and native core. A non-root amd64 container preserves the whole identity
under `/data`. Client integrations are distributed separately and require their
documented native client runtimes. Source/systemd installation remains
available.
